# User Guide

1. Sign in and select the appropriate branch, warehouse and financial period.
2. Maintain master data before transactions: products, customers, suppliers and warehouses.
3. Post purchases to increase inventory and supplier outstanding.
4. Use POS to create invoices, collect split payments and print receipts; posted sales reduce inventory and update finance.
5. Use stock adjustment/transfer/verification only with correct reason and warehouse.
6. Record receipts and supplier payments against outstanding documents.
7. Reconcile day book, cash/bank books, GST reports and dashboard summaries daily.
8. Use report filters before export. Treat exported customer, supplier and finance data as confidential.

Contact an administrator when a period is locked, permission is missing, a transaction conflicts, or a printer is unavailable. Do not share accounts or retry a financial posting after an uncertain network response without checking its status.
